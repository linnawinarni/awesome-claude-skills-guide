# Quick Assessment Checklist

Use this checklist for rapid submission evaluation.

## 30-Second Assessment

### Does it pass basic relevance?
- [ ] Clearly related to skills/resources
- [ ] Fits repository scope
- [ ] Not off-topic spam

### Does it have quality basics?
- [ ] Title is clear
- [ ] Description is understandable
- [ ] Links work
- [ ] Not obviously low-effort

### Are there trust concerns?
- [ ] Not a commercial funnel
- [ ] No mandatory paid dependency
- [ ] Not pure marketing speak
- [ ] Appears legitimate

### Does it provide value?
- [ ] Useful to more than submitter
- [ ] Not extremely niche
- [ ] Offers something new or better
- [ ] Worth including

## Decision

**All checks passed?** → Accept ✅

**Most passed but some issues?** → Request Changes 🔄

**Multiple concerns?** → Reject ❌

## If Issues Found

Note specific problems:
- [ ] Unclear description - needs specific details
- [ ] SaaS wrapper - needs standalone value
- [ ] Low quality - needs better documentation
- [ ] Too niche - may not fit general audience
- [ ] Formatting - needs to match standards
- [ ] Spam - no legitimate value

## Feedback Template

```
Thank you for the submission! 

We appreciate the contribution. However, [specific issue].

```
