# Red Flag Quick Reference

## 🚩 Commercial/SaaS Red Flags

- "Sign up for..."
- "Get started with our platform..."
- "Requires subscription to..."
- "Premium feature..."
- Heavy sales/marketing language
- Mandatory API key for paid service
- Requires commercial platform to function

## 🚩 Low-Quality Red Flags

- Single file with minimal content
- No documentation or README
- Unclear what it actually does
- Poor spelling/grammar
- Barely tested or functional
- No examples or use cases
- Looks hastily thrown together

## 🚩 Spam Red Flags

- Generic marketing buzzwords ("revolutionary", "game-changing", "powerful")
- Multiple submissions from same source
- Clearly AI-generated without substance
- Misleading or exaggerated claims
- No genuine value
- Obvious copy-paste from template

## 🚩 Scope Red Flags

- Extremely niche/narrow use case
- Only useful for one company/industry
- Duplicates existing content exactly
- Personal project, not community resource
- Too simple ("what users could do in minutes")
- Outside repository topic

## ✅ Green Flags

- Clear, specific description
- Well-maintained repository
- Documentation and examples
- Active community/contributors
- Solves real problem
- General audience appeal
- Professional presentation

## Decision Tree

```
Does it have red flags?
├─ Yes: Multiple or severe?
│  ├─ Severe: REJECT ❌
│  └─ Minor: REQUEST CHANGES 🔄
└─ No: Sufficient quality?
   ├─ Yes: ACCEPT ✅
   └─ No: REQUEST CHANGES 🔄
```
