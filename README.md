# Skills Curator

A comprehensive skill for reviewing, evaluating, and curating quality skills and resources for your repository.

## Features

- ✅ Four-dimensional assessment framework (Relevance, Quality, Safety, Value)
- ✅ Decision trees for Accept/Request Changes/Reject
- ✅ Red flag identification guides
- ✅ Quality entry formatting standards
- ✅ Feedback templates for contributors
- ✅ Scenario-based guidance

## Installation

### Claude.ai or Claude Code
1. Download the `SKILL.md` file
2. Go to Settings > Capabilities
3. Upload the skill
4. Enable it

### Claude Desktop
1. Clone or download this repository
2. Add to your skills directory
3. Restart Claude

## Usage

Ask your AI assistant:

- "Review this skill submission for our repository"
- "Is this a good fit for our curated list?"
- "Help me write feedback for this contributor"
- "Check if this violates our quality standards"
- "What's wrong with this SaaS wrapper submission?"
- "How should I format this list entry?"

## Example Use Cases

### Scenario 1: Evaluating a Submission
```
User: "I got this submission: 'EmailBot - automates email tasks'. 
It's a wrapper around Mailchimp API. Should we accept it?"

Skill Response: Identifies this as a SaaS wrapper, 
suggests rejection because it provides no standalone value.
```

### Scenario 2: Writing Contributor Feedback
```
User: "Help me provide constructive feedback on this 
PDF skill submission. They're describing it as 'powerful'."

Skill Response: Provides structured feedback template, 
suggests replacing marketing language with technical details.
```

### Scenario 3: Assessing List Entry Quality
```
User: "Is this description good enough?
'[Tool](link) - Does stuff with data'"

Skill Response: Points out vagueness, suggests 
more specific description with use case examples.
```

## What This Skill Helps With

- **Submissions Review** - Evaluate new skills and resources fairly
- **Quality Control** - Maintain consistent standards
- **Contributor Communication** - Write constructive feedback
- **Decision Making** - Apply clear, objective criteria
- **Best Practices** - Follow community curation standards

## Key Principles

1. **Value First** - Genuine utility matters most
2. **Anti-Spam** - Protect community from low-effort submissions
3. **Transparency** - Clear decision criteria and feedback
4. **Quality Over Quantity** - Fewer excellent entries > many mediocre ones
5. **Community Trust** - High signal-to-noise ratio builds trust
